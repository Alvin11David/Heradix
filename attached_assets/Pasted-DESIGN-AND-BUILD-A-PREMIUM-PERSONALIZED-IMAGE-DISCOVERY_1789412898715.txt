DESIGN AND BUILD A PREMIUM PERSONALIZED IMAGE DISCOVERY EXPERIENCE

I am building an image discovery platform with two main sections:

1. PNG
2. Photos

The goal is to create a highly attractive, modern, smooth, and personalized user experience where the system learns what the user likes before displaying recommendations.

IMPORTANT:
Do NOT copy Pinterest's UI directly. Take inspiration from the quality, simplicity, interaction patterns, and personalization concept of modern platforms like Pinterest, but create a completely original interface and visual identity.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. FIRST-VISIT PERSONALIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When a user enters either the PNG section or the Photos section for the FIRST TIME, do not immediately show a generic feed.

Instead, detect that the user has not yet selected preferences for that section and present a beautiful preference-selection experience.

The experience should feel like a premium onboarding flow rather than a boring form.

Example:

User clicks:
→ PNG

System detects:
→ No PNG preferences exist

Display:
→ Personalized PNG discovery onboarding

Likewise:

User clicks:
→ Photos

System detects:
→ No Photo preferences exist

Display:
→ Personalized Photo discovery onboarding

The PNG and Photo preference systems should be independent because a user may want completely different things from PNGs and photographs.

 │    ├── Styles

    ]
